# Third Autocorrelation Inequality

AlphaEvolve Appendix B.3. Construct a (possibly signed) step
function `f` to improve the upper bound on a constant C3 related
to the absolute value of the autoconvolution of `f`.

The program must expose `run()` returning
`(f_values, c3_achieved, loss, n_points)`.

Reward = `BENCHMARK / c3_achieved`. Maximize.
